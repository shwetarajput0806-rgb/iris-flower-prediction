# Iris Flower Prediction App

This project is a Machine Learning web application built using Streamlit and Decision Tree Classifier.  
The app predicts the species of an Iris flower based on user input features.

## Live Demo

Streamlit App Link:  
https://iris-flower-prediction-2darevv7utzwxujt6vwxt6.streamlit.app/

---

## Features

- Predict Iris flower species
- User-friendly Streamlit UI
- Decision Tree Classification Model
- Real-time prediction
- Simple and interactive interface

---

## Technologies Used

- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy

---

## Machine Learning Algorithm

- Decision Tree Classifier

---

## Dataset

- Iris Dataset from Scikit-learn

Features used:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Target Classes:
- Setosa
- Versicolor
- Virginica
